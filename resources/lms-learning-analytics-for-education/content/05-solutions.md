# 解答・検討例

本教材の演習には唯一の正解がありません。以下は、教育的に検討すべき論点の例です。

## 初級・活動1：授業設計対応表

### 確認クイズ

- 観測可能：開始、回答、再試行、提出時刻、得点
- 観測困難：推測か理解か、誤答理由、LMS外で考えた時間
- 補完：設問分析、回答理由、授業中の説明、自由記述

### 応用課題

- 観測可能：課題閲覧、提出、再提出、提出時刻、得点
- 観測困難：計画、協働、参考資料の利用、困難の理由
- 補完：成果物、ルーブリック、短い振り返り、相談記録

## 初級・活動2：事実と説明

良い記述:

> 第3週は、第1・2週よりイベント数の中央値と期限内提出率が低い。

まだ事実ではない記述:

> 第3週に学生の意欲が低下した。

代替説明には、課題難度、締切集中、教材公開の遅れ、対面活動、LMS外学習、祝日等があります。

## 初級・活動3：反例

### 低活動・高得点

- 既有知識がある
- 教材をダウンロードしてLMS外で学んだ
- 短時間で必要情報を見つけた
- 別教材を利用した

### 高活動・低得点

- 理解に苦戦して往復している
- 活動の場所を見つけにくい
- 接続が不安定で再読込が多い
- イベント数に自動通信が混ざる

どちらも、活動量だけで「よい／悪い学習者」と分類しません。

## 初級：改善案

例:

- 教育課題：第3週の応用課題で期限内提出が低下
- 根拠：提出率、教材利用時期、学生の短い振り返り
- 不確実性：課題難度と他科目の締切状況
- 変更：例題追加、締切分散、提出前チェック
- 学生への説明：学習負担の確認結果を受けて変更したと共有
- 成功指標：期限内提出、課題得点、負担感、相談数
- 副作用：活動追加による負担増

## 中級・活動1：構成概念マップ

例:

| 項目 | 内容 |
|---|---|
| 教育課題 | 課題提出が継続しない |
| 理論的概念 | 時間管理、努力調整、支援要請 |
| 観測指標 | 提出時刻、active days、支援依頼 |
| 反例 | 早く完了し活動が少ない、LMS外で計画している |
| 補完情報 | 計画の自己報告、課題成果、面談 |
| 教育的対応 | 計画テンプレート、柔軟な相談方法、締切設計 |

## 中級・活動2：判定時点で使える列

| 列 | 判定 | 理由 |
|---|---|---|
| 第3週までのactive days | 使用可能 | 判定時点で記録済み |
| 第4週の未提出 | 使用不可 | 将来情報 |
| 第3週までの仮成績 | 条件付き | 採点が完了し全員に同条件なら可 |
| 最終成績 | 使用不可 | 結果変数であり将来情報 |
| 第4週の要注意メモ | 使用不可 | 判定後に作成 |
| 学生が選択した連絡方法 | 条件付き | 支援提供に使えるが予測特徴量にする必要はない |

## 中級・活動3：支援方針

「全員支援＋追加確認」は、予測モデルの誤りによる支援格差を小さくしやすい方針です。
一方、全員への情報が多すぎると必要な学生へ届かないため、内容を短く行動可能にします。

「上位15人へ個別相談」は容量へ合いますが、順位の不確実性と閾値直下の学生を無視できません。
固定的なリスクラベルを表示せず、本人へ状況を確認します。

「説明可能な条件のみ」は透明ですが、未提出になる前の支援が遅れる可能性があります。

## 中級：公平性

確認すべき結果:

- 選択率
- 誤警告率・見逃し率
- 連絡送信率
- 到達率
- 相談実施率
- 支援後の成果
- 学生の受け止め

差があった場合、すぐに属性を除けばよいとは限りません。指標の意味、データ品質、連絡時間、
支援方法、構造的な障壁を確認します。

## 中級：介入効果

到達群と非到達群の単純比較は、支援へ応答できる条件の違いを含みます。
可能なら無作為割付、段階導入、事前に定めた比較群を用います。

最低限、次を区別して報告します。

1. 対象に選ばれた人全体の結果
2. 連絡が届いた割合
3. 支援を選択・実施した割合
4. 提出、成績、継続等の変化
5. 群別の到達と結果
6. 不安、スティグマ、業務過負荷等の副作用

## 修士発展編：研究質問の型

同じ「第3週の提出遅延」でも、問いによって必要なデザインが変わります。

| 型 | 検討例 |
|---|---|
| 記述 | 第1〜6週の期限内提出率はどのように変化したか |
| 関連 | 課題難度、活動日数、期限内提出率はどのように関連するか |
| 予測 | 第3週までの情報から、第4〜6週の未提出をどの程度識別できるか |
| 説明 | 学生と教員は第3週の提出困難をどのように説明するか |
| 因果 | 柔軟な相談時間の提供は通常案内と比べて相談到達率を改善するか |
| デザイン・評価 | 全員支援と追加確認を、誰がどの時点でどう実施すればよいか |

「相談した学生の提出率が高かった」という観察だけでは、相談の因果効果を示しません。
相談へ応答できる時間、支援要請への抵抗、もともとの学習計画等が異なる可能性があります。

## 修士発展編：構成概念妥当性

### 例：時間管理

- 理論的概念：利用可能な時間を目標へ配分し、進捗に応じて調整する
- 観測候補：活動日数、締切までの日数、提出時刻、週ごとの継続
- 反例：LMS外で計画している、まとめて学習する方略が適切、勤務時間により夜間へ集中
- 構成概念外の要因：LMSの障害、教材公開時刻、締切の集中、タイムゾーン
- 補完：計画方略の短い自己報告、課題成果、生活条件を決めつけない面談

ログと自己報告が一致しない場合、どちらかを自動的に誤りとしません。測定時点、質問文、
LMS外活動、回答しなかった学生の違いを検討します。

## 修士発展編：ロジックモデル

相談案内の例：

1. 資源：学修支援者、夕方を含む相談枠、オンライン予約
2. 活動：全員へ計画資料、希望者へ個別相談、未提出者へ非懲罰的確認
3. 直接結果：送信、閲覧、予約、到達、相談完了
4. 短期成果：課題要件の理解、実行可能な計画、支援先の認知
5. 教育成果：提出継続、理解、自己効力感
6. 前提：相談を受けても成績上の不利益がなく、方法を選べる
7. 外部要因：他科目の締切、仕事、ケア、通信環境

支援が届かなかった場合、モデルを変更する前に、連絡時間、方法、アクセシビリティ、
相談枠の設定を確認します。

## 修士発展編：評価計画

実行可能な例は、日中相談だけの期間を基準に、夕方・非同期相談を段階的に追加し、
時間帯別の到達率と相談完了率を比較する計画です。

主要評価指標を期限内提出だけにせず、次を分けます。

- 実装：送信、到達、予約、完了、対応時間
- 近位成果：課題理解、計画、支援先の認知
- 教育成果：提出、成果物の質、継続、自己効力感
- 公平性：時間帯別・履修条件別の到達と負担
- 副作用：不安、ラベル付け、相談業務の過負荷

段階導入では同時期の授業変更や学期進行が交絡します。導入時点、教材・締切変更、対象者、
通常支援を記録し、結論をそのデザインが支持する範囲へ限定します。
