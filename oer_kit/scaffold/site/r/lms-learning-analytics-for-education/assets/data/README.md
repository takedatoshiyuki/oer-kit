# 合成データの説明

このフォルダーの CSV は、教材のために作成した**完全な合成データ**です。実在する学生、授業、LMS の記録は含みません。学習者を直接評価するためではなく、授業設計と支援の改善について対話するために利用してください。

## ファイル

### `course-design.csv`

授業で設定された学習活動の一覧です。LMS の行動を解釈する前に、週、活動種別、必須・任意、成績評価、締切、教育意図を確認するために使います。

### `learner-week.csv`

60 名の合成学習者について、6 週間分の集計記録を収録しています。主な列は次のとおりです。

| 列 | 意味 | 解釈上の注意 |
|---|---|---|
| `learner_key` | 仮名化された合成 ID | 実在人物とは対応しない |
| `study_schedule` | 主な受講時間帯 | 能力ではなく生活・勤務条件の一部 |
| `prior_lms_experience` | LMS 利用経験 | 自己効力感や学習能力そのものではない |
| `event_count` | 週内のイベント数 | 多さが学習の深さを直接示すわけではない |
| `active_days` | 活動が記録された日数 | オフライン学習は観測できない |
| `material_views` | 教材表示回数 | 読解や理解の完了を保証しない |
| `assignments_on_time` | 期限内提出数 | 締切設定や生活条件の影響を受ける |
| `avg_score` | 週内課題等の平均点 | 評価設計によって意味が変わる |
| `support_request` | 支援要請の有無 | 支援ニーズのないことを意味しない |

一部に、イベント数は少ないが成績と提出が安定している学習者、イベント数は多いが困難を抱える学習者を意図的に含めています。単純な「活動量＝学習成果」という解釈を検討するためです。

### `intervention.csv`

第 1〜3 週の簡易ルールによる支援候補、連絡、到達、相談完了、その後の提出・得点をまとめています。時間帯によって連絡到達率が異なるように設計してあり、モデルの精度だけでなく支援方法の公平性を検討できます。

## 再生成

R と `tidyverse` が利用できる環境で、`content/R` フォルダーを作業ディレクトリとして次を実行します。

```r
source("00-generate-data.R")
```

同じ規則と乱数を使わない決定的な計算により、3 つの CSV が再生成されます。
